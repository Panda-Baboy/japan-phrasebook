PandaBaboy Japan Phrasebook V3.5 — MAIN BRANCH UPLOAD PACKAGE

STATUS: V3.5 working preview. Not the full planned feature set.

UPLOAD:
1. Back up existing in-app purchases, outfits and other local data first.
2. On GitHub, open Panda-Baboy/japan-phrasebook and select main.
3. Extract this ZIP on your computer. Upload the WEBSITE FILES from inside (not the ZIP itself and not a containing folder) to the repository root, replacing matching files.
4. Commit changes, wait for the Pages deployment to finish, then visit https://panda-baboy.github.io/japan-phrasebook/?v=350
5. Test phrases, favourites, outfit planner, purchases, manual import/export, clothing builder, and offline use before entering important data.

INCLUDED IN PREVIEW: removal of outdated V3.3 ribbon, J/K purchase tracker categories and separate budgets, manual JSON sync, wishlist, dropdown clothing sentence builder, sample conversation practice, offline caching.

NOT YET IMPLEMENTED: live J/K cloud sync, full conversation course, comprehensive izakaya training, full character-learning upgrades, guaranteed offline recorded audio.

WARNING: Live sync is NOT included. Purchases entered on one phone do not automatically appear on the other. Import/merge is manual. This is a preview build, not a fully tested production release.
