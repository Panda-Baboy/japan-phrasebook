PANDABABOY JAPAN PHRASEBOOK — V3.6 TEST RELEASE

IMPORTANT: This is a full upload package, not a tested production release. Keep a backup of the working V3.5.1 repository and export in-app data on EACH device before uploading.

UPLOAD
1. Extract this ZIP.
2. Upload the FILES INSIDE the extracted folder to the ROOT of your GitHub Pages repository's main branch (not the folder or ZIP).
3. Replace matching files, add v36.js and v36.css, and commit.
4. Wait for GitHub Pages deployment and open https://panda-baboy.github.io/japan-phrasebook/?v=360
5. If the old app persists, close the Home Screen app and refresh in Safari. Offline service workers may retain cached files until refreshed.

ADDED
- Global English ON/OFF and independent romaji toggle; saved per device.
- Reveal English in Conversation Practice; existing 50 scenarios retained.
- Izakaya guided phrases, Travel Rescue, Learning Lab recognition cards.
- Separate K/J packing checklists, purchase tracker shortcut and tax-free reminders.
- Couple challenges and individual completion markers.
- Full V3.6 backup export/import with deduplication of purchases and wishlist; manual transfer only.
- Audio and phrasebook, outfit planner, purchases and wishlist code preserved.

LIMITATIONS
- No live cloud synchronization. Each phone stores data separately.
- Speech depends on device Japanese voice; offline playback not guaranteed.
- Learning Lab is self-assessed, not stroke-order animation or handwriting recognition.
- English OFF hides translations in phrase cards and practice; general instructions and hints can remain in English. Some existing builders still show explanatory labels.
- Tax-free eligibility, shop procedures and regulations can change. Confirm official current rules.
- Imports can replace some trip settings/outfits. Back up both devices first.
